# 3D Earth Explorer

Interactive React/Vite globe for exploring countries, US states, and state capitals.

## Features

- 3D Earth view powered by `react-globe.gl`
- World country boundaries from public GeoJSON data
- US state boundaries with optional capital labels
- Clickable regions with kid-friendly country/state explanations
- World and USA camera presets

## Local Development

```bash
npm install
npm run dev
```

## Quality Checks

```bash
npm run lint
npm run build
```
